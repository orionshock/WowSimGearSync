Upgrade and profession-effect observations (MoP Classic, Interface 50504)

UPGRADE OBSERVATION
EquipmentInspector owns a reusable hidden GameTooltip. Each inspection clears
it, sets the inventory item, verifies tooltip/link identity, reads font strings,
and hides it. It matches the localized ITEM_UPGRADE_TOOLTIP_FORMAT, including
positional integer placeholders, without English fallback text.
Consistent current/maximum values establish eligibility and remaining upgrades.
A populated identity-checked tooltip without the upgrade line establishes that
the item is not upgradeable. Failed, stale, uncached, or conflicting data stays
UNKNOWN. No item exceptions or fixed maximum count are hardcoded.

Comparison targets the observed maximum even if imported upgradeStep is lower
or omitted. NPC/ItemUpgrades lists matching items with upgrades remaining.
A row click checks identity/GUID, cursor, locks, and vendor availability, then
uses C_ItemUpgrade.SetItemUpgradeFromCursorItem to stage the item. Selected-vendor
data supplies next cost and affordability. WSGS never calls UpgradeItem; the
player purchases through Blizzard's Upgrade button. Selected-vendor data is
not an arbitrary-equipped-item observation API.

PROFESSION EFFECTS
C_Item.GetItemSpell receives the actual equipped link. Slot-specific mappings
in ModificationMaterials include:
- Hands: 126734 -> 4898 Synapse Springs; 108788 -> 4697 Phase Fingers;
  109076 -> 4698 Incendiary Fireworks.
- Back: 126389 -> 4897 Goblin Glider.
- Waist: 55004 -> 4223 Nitro Boosts; 131459 -> 5000 Watergliding Jets.
Cloak use spell 55001 establishes a different Parachute effect without choosing
between enchantments 3605 and 3859, which share that use spell.
Missing or unmapped use spells stay UNKNOWN. Cached metadata alone does not
prove a missing tinker. Ordinary enchants and unverified link fields are not
substitutes for tinker observations.

The optional Goblin Glider fallback applies only to an omitted cloak tinker on
an Engineer. Explicit imports take priority; gloves and belts have no fallback.
See direct-profession-enhancements.txt for recipe execution.

REFERENCE CONTRACTS
Local Blizzard generated Item documentation defines GetItemSpell and socket
APIs. Blizzard_ItemUpgradeUI/Mists reads selected-vendor currUpgrade, maxUpgrade,
and the next upgradeLevelInfos entry. WowSimsExporter and installed
CharacterStatsPaneImproved demonstrate inventory-tooltip upgrade inspection;
WSGS uses its own localized parser and identity checks. Local MoP effect data
corroborates use-spell mappings. These references do not establish runtime success
for every recipe, locale, item, or NPC interaction.
