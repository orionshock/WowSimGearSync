Task 024: Direct profession enhancements — MoP Classic only

Execution contract

Direct item-targeting recipes reuse the slot-click sequence already proven for
Engineering: open the profession through its profession spellbook button, find
the exact recipe link, verify reagents/tools/cooldown and selection, call
DoTradeSkill, and target the equipped item with UseInventoryItem. No protected
step is deferred to an event or timer. Events only verify the resulting equipped
state and close the TradeSkill frame after UNIT_SPELLCAST_SUCCEEDED.

Inscription boundary

Secret Inscription profession recipes create BoP enhancement items instead of
starting item targeting. Creating them would be intermediate-item crafting, so
it is deliberately not automated. Already-carried finished items remain usable:
4912/87581 (Ox Horn), 4913/87585 (Tiger Fang), 4914/87584 (Tiger Claw), and
4915/87582 (Crane Wing).

Socket observation

C_Item.GetItemNumSockets(target item ID) establishes the native socket count.
An imported Wrist or Hands gem position beyond that count requests the
Blacksmithing socket. C_Item.GetItemNumAddedSockets(equipped link) independently
verifies the added socket before gem planning advances. Native sockets are not
treated as profession-added sockets.
