Active import and options (MoP Classic, Interface 50504)

AceDB uses WSGSDB, enabled by the TOC SavedVariables declaration.
db.char.activeImport holds one normalized configuration: equipment, class,
specialization, apiVersion, name, metadata, and exact sourceJSON for ReforgeLite.
There is no per-spec collection, selection key, customName flag, or set-ID
association. No old-schema migration is provided.

ImportInto decodes and validates before SaveBuild replaces activeImport.
Invalid exports leave the previous import intact. Each successful import resets
the name to specialization.name. GetActiveSimulationProfile returns activeImport;
its historical function name does not imply multiple stored profiles.
RenameBuild checks the expected active table, trims whitespace, rejects empty
names and names over 16 UTF-8 characters, and invalidates Equipment State.
A new import table discards old modification verification through existing
build-replacement handlers without taking ownership of a player's cast/cursor.

EquipmentSetSync resolves the exact active name at synchronization time.
Existing sets keep their icon and shirt/tabard ignored-slot settings; new sets
use the specialization icon and ignore shirt/tabard. The save path restores the
caller's ignored-slot selection and verifies saved results. Renaming an import
changes future destinations; it never renames or deletes a different set.
Synchronization requires matching items, verified batch records when present,
and a snapshot for the current import. Modifications need not be complete.
Disabling integration skips create/update work without changing stored sets.

AceConfigDialog:AddToBlizOptions registers the AceGUI panel in Blizzard Settings.
/wsgs options and launcher right-click open it. General options use db.profile:
debug=false, engineeringCloakFallback=true, equipmentSets=true.
The Debug entry point gates verbose logs, not important player messages.
The cloak option supplies Goblin Glider effect 4897 only for Engineers with an
omitted cloak tinker. Explicit targets, including zero, win. Gloves and belts
receive no fallback. No default is written into imported equipment.
